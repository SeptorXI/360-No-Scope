# Clear Glass

Craft clear glass blocks directly from sand and turn them into connecting panes at the Builder's Workbench.

| Version | Hytale server range | Mod identifier |
| --- | --- | --- |
| 0.1.2 | `>=0.7.5 <0.8.0` | `Steven:ClearGlass` |

## Build

From the collection root, run this Python command.

```powershell
python build.py mods/utility/clear-glass
```

The output is `dist/Clear-Glass-0.1.2.zip` under this project. The locally archived server build and its SHA-256 are listed in [project.json](project.json).
