# Brotherhood Sanctuary Relics

Four furnishings for a Brotherhood sanctuary, including an effigy, altar, banner and reliquary.

| Version | Hytale server range | Mod identifier |
| --- | --- | --- |
| 0.1.4 | `>=0.7.5 <0.8.0` | `Steven:CrimsonBrotherhoodDecor` |

## Build

From the collection root, run this Python command.

```powershell
python build.py mods/crimson-brotherhood/crimson-brotherhood-decor
```

The output is `dist/Crimson-Brotherhood-Decor-0.1.4.zip` under this project. The locally archived server build and its SHA-256 are listed in [project.json](project.json).
