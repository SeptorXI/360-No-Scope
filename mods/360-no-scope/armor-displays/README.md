# Armor Displays

Armor stands, single wall holders and vertical gun racks with native inventory storage that preserves equipment metadata.

| Version | Hytale server range | Mod identifier |
| --- | --- | --- |
| 0.1.10 | `>=0.7.5 <0.8.0` | `Steven:Armor Displays` |

## Build

From the collection root, use Python and JDK 25. Supply your own Hytale server JAR and any compile dependencies below.

```powershell
python build.py mods/360-no-scope/armor-displays --server-jar PATH_TO_SERVER_JAR
```

The output is `dist/Armor-Displays-0.1.10.jar` under this project. The locally archived server build and its SHA-256 are listed in [project.json](project.json).
