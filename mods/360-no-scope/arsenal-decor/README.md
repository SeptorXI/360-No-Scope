# Arsenal Relics

Eleven home decorations based on the weapon families, regions and lore of 360 No Scope.

| Version | Hytale server range | Mod identifier |
| --- | --- | --- |
| 0.1.4 | `>=0.7.7 <0.8.0` | `Steven:ArsenalDecor` |

## Build

From the collection root, run this Python command.

```powershell
python build.py mods/360-no-scope/arsenal-decor
```

The output is `dist/Arsenal-Decor-0.1.4.zip` under this project. The locally archived server build and its SHA-256 are listed in [project.json](project.json).
