# Death Lore Decor

Four furnishings inspired by Darksiders II, including a Reaper statue, Well of Souls, Tree of Death and Book of the Dead lectern.

| Version | Hytale server range | Mod identifier |
| --- | --- | --- |
| 0.1.4 | `>=0.7.5 <0.8.0` | `Steven:DeathLoreDecor` |

## Build

From the collection root, run this Python command.

```powershell
python build.py mods/pale-rider/death-lore-decor
```

The output is `dist/Death-Lore-Decor-0.1.4.zip` under this project. The locally archived server build and its SHA-256 are listed in [project.json](project.json).
