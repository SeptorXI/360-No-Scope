# Relics of the Black Tempest

A Storm Tyrant monument, Captive Storm Holocron and throne that players can sit on.

| Version | Hytale server range | Mod identifier |
| --- | --- | --- |
| 0.1.5 | `>=0.7.7 <0.8.0` | `Steven:TempestDecor` |

## Build

From the collection root, run this Python command.

```powershell
python build.py mods/black-tempest/tempest-decor
```

The output is `dist/Tempest-Decor-0.1.5.zip` under this project. The locally archived server build and its SHA-256 are listed in [project.json](project.json).
