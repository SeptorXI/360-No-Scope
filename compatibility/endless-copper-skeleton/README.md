# Endless Leveling Copper Skeleton Fix

Restores the melee damage interaction for the Copper Skeleton summon in Endless Leveling.

| Version | Hytale server range | Mod identifier |
| --- | --- | --- |
| 1.0.1 | `>=0.7.0 <0.8.0` | `Steven:EndlessLevelingCopperSkeletonFix` |

## Dependencies

- `Alechilles:Alec's Tamework!` `>=5.7.0 <6.0.0`
- `Airijko:EndlessLevelingCore` `=14.5.6`
- **Alec’s Patchwork** must load the patch data.

## Build

From the collection root, run this Python command.

```powershell
python build.py compatibility/endless-copper-skeleton
```

The output is `dist/EndlessLeveling-CopperSkeletonFix-1.0.1.zip` under this project. The locally archived server build and its SHA-256 are listed in [project.json](project.json).
